# Лабораторная работа №2: Управляющие конструкции и структуры

## Описание
Вторая лабораторная работа по курсу Go. Демонстрирует:
- Условные конструкции (`if/else`)
- Циклы (`for`, `range`)
- Функции с возвратом значений
- Работа со строками (UTF-8)
- Структуры и методы
- Ввод данных с клавиатуры
